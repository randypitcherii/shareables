Slim CI invariants

Production is the reference

  • The production job captures the manifest in a stable volume path
  • CI has read-only access to the production volume
Trusted state

No state means full build

  • A missing manifest does not produce a false success
  • The job builds the full project when state is unavailable
Safe fallback

Failures stay available

  • Successful runs clean their disposable schemas
  • Failed schemas remain for investigation until a later sweep
